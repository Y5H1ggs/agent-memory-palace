# v0.1.0 — 第一个公开版本

> 一个会遗忘、会被情绪加固、会讲自己故事的记忆系统。零第三方依赖，8.4k 行 Python。

这是 **0.1.0**：功能完整、可运行、自带 215 项断言与 18 条突变审计，但 API 尚未冻结，
也没打算现在就被当成生产依赖（原因见 README 的「成熟度自评」）。

## 它能做什么

- **幂等衰减**：权重 = 锚点 + 时间的纯函数，GC 跑一次和一百次账本一致
- **情感双刃**：情绪让记忆更难忘，同时让编码更不可靠，且不可靠不会随时间恢复
- **情绪有来源**：从文本词表与运行时结果推断，带 `source` / `drivers`，可以追问「它凭什么发烫」
- **沉淀单向门**：结构 + 语义双通道结晶，碎片降级为溯源窗口，而不是被反复压榨
- **可审计的遗忘**：重要性四分量 + 两套遗忘律 + 固定预算，每条判决都有理由
- **自述是投影**：图里不会多出一个「我」；叙事地位会随时间退潮（最近讲的活，半年前讲的走）
- **人格四层**：基座只读、人格带惯性、人设可换可回滚、变更留差异
- **自修正有边界**：12 个白名单参数 + 逐参数值域 + 冷却 + 回滚 + 拒绝用滞后指标判决
- **语义可解释**：多义词按上下文分份额（`资金` 在板块语境 93.5% 归板块），概念词从语料自学

## 怎么验

```bash
python -m memory_palace.demo    # 215 项断言 + 18 条突变审计，约 0.9 秒
python examples/quickstart.py   # 60 行示例
```

自测里最有价值的不是「全绿」，而是那 18 条**突变审计**：故意把实现弄坏（衰减带副作用、
去掉风格裁决、假语义全零向量、白名单失效、结构熵写死……），断言必须变红。
其中一条自己写错过——用 `lr=1.0` 制造「无惯性」，结果一步撞天花板，饱和伪装成惯性，
坏实现照样通过；已改成常数学习率的反事实并写进注释。

## 已知局限（不藏）

1. 语义层不是 embedding：概念种子 + 字符 bigram + 语料学习，语料上万条会退化。
2. 测试是作者自证：215 项断言只覆盖我想到的行为，18 条突变只覆盖我想到的破坏方式。
3. 自修正的「变好」仍是单指标，没有离线回放/反事实评估。
4. 单写者：两个进程写同一快照会互相覆盖（写是原子的，锁不是跨进程的）。

**不适用**：生产级记忆后端、向量检索替代品、高价值不可再生数据。
**适用**：研究记忆机制、给 agent 做可解释的长期记忆原型、当教材读。
